## Learning Path

A practical sequence through this collection:

1. **Gobuster Path Hunt** — begin with basic web path discovery.
2. **LFI on the Loose** — introduce Local File Inclusion concepts.
3. **NFS LFI Shell Game** — combine LFI and NFS-related concepts.
4. **NFS LFI Pivot** — continue with pivot-focused security analysis.
5. **Shell to Share** — explore shell and share-access relationships.
6. **TTY Shift: Stable Shell Escape** — develop TTY and shell-handling skills.
7. **SUID Bash Breakout** — study SUID and Bash security concepts.
8. **NFS Backdoor** — investigate NFS-related security scenarios.
9. **NFS Root Squash Breakout** — examine root-squash concepts.
10. **LinPEAS NFS to Root** — practice structured Linux security enumeration.
11. **NFS to Root: Linux LPE Lab** — consolidate NFS and Linux LPE concepts.
12. **NFS Root Slip** — apply the collection's NFS and privilege-focused skills in a broader CTF challenge.

## How to Use the Labs

* Open each challenge through its direct Learn SecByte URL.
* Read the objective and scope before starting.
* Begin with enumeration and document your observations.
* For NFS labs, study exports, permissions, and root-related security concepts.
* For Linux LPE labs, examine permissions and system configuration within the authorized environment.
* For LFI labs, understand how application-controlled file access can affect security.
* For Gobuster practice, document discovered paths and their relevance.
* Use LinPEAS only within systems where you have explicit authorization.
* Record your methodology and lessons learned rather than focusing only on the final result.
